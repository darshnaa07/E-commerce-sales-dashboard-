# E-commerce-sales-dashboard

## 📊 Project Overview

This project analyzes fictional e-commerce sales data and presents the results through an interactive sales dashboard created using Microsoft Excel / Google Sheets.

The project focuses on understanding sales performance, product performance, category contribution, and salesperson performance.

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing salespersons
- Compare sales across product categories
- Analyze product-wise sales
- Track sales trends over time
- Create meaningful KPIs and visualizations

## 🗂️ Dataset

The dataset contains 50 fictional e-commerce sales records.

### Main columns

- Order ID
- Date
- Customer Name
- Product
- Category
- Quantity
- Unit Price
- Discount
- Payment Method
- Salesperson
- Net Sales

## 🔧 Project Process

The project was completed in the following steps:

1. Raw data collection
2. Data cleaning and quality checking
3. Data analysis
4. KPI calculation
5. Sales summaries
6. Data visualization
7. Dashboard creation

## 📈 Dashboard Insights

The dashboard includes:

- Total Orders
- Total Quantity Sold
- Gross Sales
- Total Discounts
- Net Sales
- Average Order Value
- Highest Sale
- Lowest Sale
- Sales by Salesperson
- Sales by Category
- Sales by Product
